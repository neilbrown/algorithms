# Algorithms

I enjoy exploring algorithms.  They often contain a depth that is not
immediately obvious and does not strictly need to be understood in order
to implement them.

So here I have a collection of algorithms that interested me, described
and implemented in "literate programming" style.  The first entry is not
really an algorithm, but it is a tool for extracting C-code from
mark-down literate programs.

I hope you enjoy these and if you would like me to write about some
other algorithm, please email me <neil@brown.name>.

If you want to look at the tools and samples, you can find them on github
at <https://github.com/neilbrown/algorithms>
